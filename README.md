## 在 VSCode 里 AI 助手没有反应怎么办？

如果你在 VSCode 中向 GitHub Copilot 或其他 AI 助手提问时没有得到回应，可以尝试以下解决方法：

### 1. 检查网络连接
- 确认你的网络连接正常，可以访问外部网站。
- 如果使用了代理或 VPN，尝试切换或关闭它，再重试。

### 2. 检查登录状态
- 点击 VSCode 左下角的账户图标，确认你已登录 GitHub 账户。
- 如果未登录或登录已过期，重新登录后再试。

### 3. 重新加载窗口
- 按下 `Ctrl+Shift+P`（Mac 上为 `Cmd+Shift+P`）打开命令面板。
- 输入并执行 **"Developer: Reload Window"**（重新加载窗口）。

### 4. 检查扩展状态
- 打开扩展面板（`Ctrl+Shift+X`），找到 GitHub Copilot 扩展。
- 确认扩展已启用，如有更新请先更新。
- 尝试禁用后重新启用扩展。

### 5. 查看输出日志
- 按下 `Ctrl+Shift+U` 打开输出面板。
- 在下拉菜单中选择 **"GitHub Copilot"**，查看是否有错误信息。

### 6. 检查服务状态
- 访问 [GitHub Status](https://www.githubstatus.com/) 页面，确认 GitHub Copilot 服务是否正常运行。

### 7. 重启 VSCode
- 完全关闭并重新打开 VSCode。

### 8. 重新安装扩展
- 如果以上方法都无效，尝试卸载 GitHub Copilot 扩展后重新安装。

---

如果问题仍然存在，可以在 [GitHub Copilot 社区讨论区](https://github.com/orgs/community/discussions/categories/copilot) 寻求帮助。
